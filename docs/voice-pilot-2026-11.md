# Озвучка сюжетного режима: сравнение TTS и план пилота

Дата: 2026-11-04. Исследование без правок кода, ничего не закоммичено. Решает хозяин.

## Рекомендация

- **Основной: ElevenLabs, платный тариф на один месяц** (Starter $6 для пилота, Creator ~$22 для всей кампании). Лучшее качество и характер голоса, голоса на каждого персонажа, платный план даёт коммерческую лицензию на выход (на Free только некоммерческое использование, см. ниже).
- **Бесплатный запасной: Azure Speech, тариф F0** (0,5 млн знаков в месяц бесплатно, это больше всего объёма кампании, ~134 тыс.). Нужен аккаунт Azure с картой. Русские нейроголоса (Svetlana, Dmitry, Dariya) знаю по памяти, на странице цен их имён нет: проверить в Speech Studio до генерации.

- Решение «брать ли озвучку вообще» не зависит от поставщика: пилот на ~5 тыс. знаков стоит $6 (ElevenLabs) или $0 (Azure).

## 3. Технически

- **Формат: Opus в WebM/Ogg, моно, 24 кбит/с**, запасной mp3 64 кбит/с для старых Safari (Safari держит Opus в `.mp4/.caf`, надёжнее взять AAC-LC 48 кбит/с `m4a` как один формат для всех, если не хочется двух). Скорость речи ~15 знаков/с.
- **Размер:** диалоги = ~35 тыс. знаков/язык ≈ 40 мин ≈ **7 МБ на язык** (Opus 24k); с рассказчиком (всё) ≈ 75 мин ≈ 14 МБ на язык; mp3 64k втрое больше. Один день ≈ 100–250 КБ.
- **Не грузить всё сразу:** файлы лежат в `public/voice/<locale>/<mission-id>/<n>.opus` и **не в precache**; грузятся по одному при нажатии «слушать» (и один шаг вперёд заранее). Из-за размера лучше отдавать с GitHub/Cloudflare Pages как статику; для Pages лимит 25 МБ на файл и 20 000 файлов не мешает.
- **Кеш в service worker:** по образцу кеша Pyodide ([памятка](../../../../../.claude/projects/D--docs-2--study-Claude-0--Claude-code-22--Quaera/memory/querium-sw-pyodide-cache.md)): отдельный кеш `quaera-voice-v1`, **не привязанный к версии сборки** (иначе каждый деплой стирает), `activate` его не трогает; в `sw.js` ручной маршрут `cache-first` на `/voice/`. Версию менять только при перегенерации звука. Предкачку «неделя целиком» оформить кнопкой «скачать озвучку недели» (аналог согласия на Pyodide), по умолчанию — по одному.
- **Фолбэк:** если файла нет (миссии вне пилота, офлайн без кеша, ошибка загрузки) — текущий `speakLines` на `speechSynthesis`. Решение по реплике: есть `voice/<...>` → `<audio>`, нет → TTS. Манифест `voice/manifest.json` со списком готовых реплик (id, длительность), без обхода сети для проверки существования.
- **Субтитры «как в комиксе»:** текст уже стоит в пузырях сообщений; озвучка только подсвечивает текущую реплику (как сегодняшний `onActive`). Длительность берётся из манифеста, подсветка по событию `ended`. Дорожка аудио — дополнение к тексту, не замена (доступность, звук выключен в офисе).
- **Идентификатор реплики:** стабильный ключ `missionId + место + индекс`; при правке текста реплики файл устаревает — в манифесте хранить хеш текста, гейт `verify` (новый, `test:voice-manifest`) сверяет хеш с текущим текстом и падает при расхождении (иначе звук рассказывает не то, что написано; та же болезнь, что «число в прозе без проверки»).
- **Нормализация имён:** до генерации ввести в `storymode.ts` id говорящего (`aoki`, `manager`, `mori`, `ito`, `tanaka`, `narrator`), а не разбирать строку `from`.
- **Лицензия аудио:** положить `LICENSE-CONTENT`-пометку «аудио сгенерировано синтезом речи (поставщик), CC BY-NC-SA 4.0» и честную пометку в интерфейсе «синтезированный голос».

## 4. План пилота

**Сцена:** неделя 1, день 1 («Первый день», `day-1-first-day`) и день 2 (`day-2-counting`): Аоки-сан, «Ваш руководитель» и, если хозяину нужна третья роль, Ито-сан из «разговора между делом» среды (`day-3-shape-of-the-year`, 6 реплик во всей кампании). Объём: день 1 — 4 реплики (RU 1 501 / EN 1 615 знаков), день 2 — 6 реплик (RU 1 061 / EN 1 184). **Итого пилот: 10 реплик, 2,6 тыс. знаков RU + 2,8 тыс. EN ≈ 5,4 тыс. знаков, ~6 минут звука.** С Ито ещё ~600 знаков.

Шаги для сессии Sonnet (правила заданы, работа механическая); хозяин сам запускает генерацию своим ключом, ключа в репозитории нет:

1. **Хозяин (вне сессии):** выбрать поставщика, прослушать по 2–3 голоса на роль в его песочнице (Aoki — женский деловой, руководитель — мужской спокойный, по желанию Ито — мужской моложе), записать id голосов; сохранить ссылку на условия лицензии вывода с датой.
2. **Sonnet, шаг 1:** ввести `speaker` (id) в `StoryMessage` для миссий пилота и функцию `speakerId(from)` с нормализацией имён; `tsc` и существующие гейты зелёные.
3. **Sonnet, шаг 2:** `scripts/gen-voice.mjs` — читает реплики миссий пилота из `storymode.ts`, вырезает код, берёт ключ из переменной окружения (`QUAERA_TTS_KEY`, **не из файла**), пишет `public/voice/<locale>/<mission>/<n>.opus` и `public/voice/manifest.json` (хеш текста, длительность). Режим `--dry-run` печатает число знаков и оценку стоимости. Хозяин запускает сам.
4. **Sonnet, шаг 3:** плеер `<audio>` в `VoiceButton`: если реплика есть в манифесте — играть файл, иначе старый `speakLines`; подсветка реплики по `onActive`; правило флага `?voice=1` остаётся для пилота.
5. **Sonnet, шаг 4:** кеш `quaera-voice-v1` в `sw.js` / `postbuild-sw.mjs`, не в precache; проверка в `preview`, что после деплоя кеш не стёрт.
6. **Sonnet, шаг 5:** гейт `test:voice-manifest` (хеши, наличие файлов, размер ≤ 400 КБ на реплику); `npm run verify` и `tsc`.
7. **Хозяин:** прослушать на телефоне и в Edge; показать однокурсникам и участникам Ignite, вердикт «стоит ли на всю кампанию».
8. **Если «да» — Opus решает** про расширение: диалоги (167 реплик) → все или только брифы, нужен ли рассказчик для суждения и крючка (+30 тыс. RU и +34 тыс. EN знаков), русская озвучка в первую очередь или английская.

Оценка работы Sonnet: шаги 1–6 примерно одна сессия; генерация у хозяина — минуты; расходы на пилот $0–6.

## Как запустить генерацию (для хозяина, PowerShell)

Код пилота готов (английский, дни 1 и 2, 10 реплик, 2 779 знаков), записей пока нет: приложение читает реплики голосом браузера, как раньше. Генерируете вы своим ключом; ключа в репозитории нет.

1. **Выбрать поставщика и прослушать голоса.** ElevenLabs (платный месяц Starter, $6, 2 779 кредитов из 30 000) или Azure F0 ($0). Сохраните ссылку на условия лицензии вывода с датой. Подобрать в песочнице поставщика по голосу на роли: Aoki (женский деловой), «Your manager» (мужской спокойный). Остальные роли пилот не использует.
2. **Вписать id голосов** в `scripts/voice-cast.json` вместо `TODO-...` для `aoki` и `manager` (ElevenLabs: voice id; Azure: имя голоса из каталога Speech Studio). Остальные заглушки можно оставить.
3. **Посмотреть, что уйдёт на синтез, без ключа и без трат:**
```powershell
cd "D:\docs\2. study\Claude\0. Claude code\22. Quaera\quaera"
node scripts/gen-voice.mjs --dry-run
```
4. **Задать ключ только в текущем окне PowerShell** (в файл и в репозиторий он не попадает; закроете окно, переменная исчезнет). Для Azure ещё регион:
```powershell
$env:QUAERA_TTS_KEY = "ваш-ключ"
$env:QUAERA_TTS_REGION = "westeurope"   # только для Azure
```
5. **Запустить генерацию.** Повтор безопасен: актуальные записи пропускаются и не тратят знаки; `--only day-2-counting` берёт один день. Появятся `public/voice/en/<день>/<слот>.<хеш>.opus` и обновится `public/voice/manifest.json`. Если ElevenLabs не примет формат opus, добавить `--format mp3`.
```powershell
node scripts/gen-voice.mjs --provider elevenlabs   # или: --provider azure
```
6. **Проверить гейт и послушать:**
```powershell
npm run test:voice-manifest
npm run dev
```
Открыть `http://localhost:5173/?voice=1`, режим истории, дни 1 и 2: кнопка «Listen» на брифе играет файл (во вкладке Network виден запрос `/voice/en/...`). Реплики после задания (`after`) генерируются, но в интерфейсе пока не воспроизводятся: кнопки на них нет.
7. **Закоммитить результат:** `public/voice/` и `scripts/voice-cast.json` (id голосов не секрет). Ключ нигде не сохранять. Дальше телефон, Edge, показ однокурсникам и Ignite (шаг 7 плана).

## Как запустить генерацию для всей кампании (диалоги, EN)

Решение 2026-11-05: озвучиваем диалоги (брифы, реплики после задания, разговоры между делом), рассказчика (`reflection`, `hook`) нет. Сначала прослушка встроенным голосом: `http://localhost:5173/?voice=audition` (по реплике на персонажа, «все реплики подряд», выбор голоса, сохраняется в браузере), потом `?voice=1` и режим истории.

```powershell
cd "D:\docs. study\Claude . Claude code. Quaera\quaera"
node scripts/gen-voice.mjs --scope dialogs --dry-run
```

`--dry-run` печатает знаки по персонажам, неделям и видам и нарастающий итог по неделям. Сейчас: 167 реплик, 36 036 знаков; в Starter (30 000 кредитов) целиком не влезает. Варианты: `--kinds brief,interlude` (86 реплик, 20 719 знаков), либо неделями по `--only <id миссии>`, либо Creator.

Подставьте id голосов вместо `TODO-...` в `scripts/voice-cast.json` для `aoki`, `manager`, `mori`, `ito`, `tanaka` (рассказчик не нужен), задайте `QUAERA_TTS_KEY` в окне PowerShell и запускайте:

```powershell
node scripts/gen-voice.mjs --scope dialogs --provider elevenlabs --kinds brief,interlude
node scripts/gen-voice.mjs --scope dialogs --provider elevenlabs   # докачать остальное, готовые записи пропускаются
```

Затем `npm run test:voice-manifest` и коммит `public/voice/` и `scripts/voice-cast.json`. Если манифест частичный, реплики без записи идут голосом браузера; очередь экрана играет файлы, только если записи есть у всех его реплик.
